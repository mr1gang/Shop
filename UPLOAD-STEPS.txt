  راهنمای کوتاه: آپلود این فروشگاه روی GitHub  (فقط همین یک کار!)
══════════════════════════════════════════════════════════════

۱) این فایل ZIP را روی کامپیوتر باز کنید (راست‌کلیک → Extract All).
   پس از باز کردن، این‌ها را می‌بینید:
      index.html            ← فروشگاه مشتریان
      admin.html            ← پنل مدیر (رمزدار)
      README.md             ← راهنمای کامل فارسی
      assets/  tools/  sw.js  manifest.webmanifest
      .github/  .nojekyll   ← (فایل‌های مخفی؛ اگر نمایش داده نمی‌شوند مهم نیست)

۲) وارد سایت github.com شوید و یک مخزن (Repository) جدید بسازید
    (نامش مثلاً: myshop)  —  نوع Public  —  دکمه‌ی Create را بزنید.

۳) در صفحه‌ی مخزن روی «uploading an existing file» (یا Add file → Upload files) بزنید.

۴) داخل پوشه‌ی استخراج‌شده بروید، Ctrl+A بزنید (انتخاب همه) و همه را
    با ماوس داخل کادر آپلود GitHub بکشید و رها کنید.
    ⚠️ مهم: خودِ فایل‌ها باید در «ریشه‌ی مخزن» باشند، نه داخل یک پوشه‌ی تودرتو.
    (بعد از آپلود باید index.html را مستقیماً در صفحه‌ی اول مخزن ببینید.)

۵) پایین صفحه «Commit changes» را بزنید و صبر کنید تا آپلود تمام شود.

۶) به Settings → Pages بروید:
      Source  →  Deploy from a branch
      Branch  →  main        Folder →  / (root)      سپس Save

۷) چند دقیقه صبر کنید (تب Actions). آدرس سایت شما:
      https://USERNAME.github.io/myshop/            ← فروشگاه مشتریان
      https://USERNAME.github.io/myshop/admin.html  ← پنل مدیر

      ورود اولیه‌ی پنل:   نام کاربری: admin        رمز: admin123
      (بعد از اولین ورود، از «تنظیمات» رمز را عوض کنید.)

──────────────────────────────────────────────────────────────
• خواستید همین حالا بدون آپلود تست کنید؟ فایل‌های
  single-store.html و single-admin.html را دوبار کلیک کنید.
• سؤال یا مشکلی بود، بخش «راهنما و انتشار» داخل خود پنل و
  فصل ۶ فایل README.md را ببینید.
