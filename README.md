# 🏪 سامانهٔ مدیریت فروشگاه (نسخهٔ بدون سرور)

یک سایت کامل مدیریت فروشگاه که **فقط روی GitHub Pages اجرا می‌شود** — بدون سرور، بدون نصب، بدون هزینه.
همه‌چیز در خود مرورگر ذخیره می‌شود و کل سایت آفلاین هم کار می‌کند.

سایت **دو بخش** دارد:

| بخش | فایل | توضیح |
|---|---|---|
| 🔐 **پنل صاحب فروشگاه** | `admin.html` | با نام کاربری و رمز وارد می‌شوید؛ اجناس، قیمت‌ها، موجودی انبار، فروش و تنظیمات اینجاست. |
| 🛍️ **فروشگاه مشتریان** | `index.html` | ویترین زیبا برای مشتری: جست‌وجو، جزئیات کالا، بارکد، سبد خرید و ثبت سفارش. |

**ورود اولیه:** نام کاربری `admin` و رمز `admin123` — بعد از اولین ورود از بخش «تنظیمات» عوضش کنید.

## ۱) همهٔ امکاناتی که خواسته بودید

| خواسته | جای آن در سایت |
|---|---|
| مدیریت تعداد و موجودی اجناس | بخش «انبار و موجودی» + گردش انبار + انبارگردانی + هشدار کم‌موجودی |
| مدیریت قیمت | بخش «اجناس فروشگاه» (قیمت خرید، فروش، عمده، مالیات) |
| ماشین‌حساب افزایش/کاهش قیمت با درصد | بخش «ماشین‌حساب قیمت» + تغییر گروهی قیمت با ٪ + دکمه‌های ٪ در فرم هر جنس |
| هوش مصنوعی: عکس کالا → همهٔ جزئیات | در فرم جنس، کادر «عکس و شناسایی هوشمند»؛ عکس را می‌کشید و می‌اندازید یا با دوربین می‌گیرید و «تحلیل هوشمند تصویر» را می‌زنید |
| کارکرد بسیار ساده | همه‌چیز فارسی، بزرگ و یک‌کلیکی؛ هر صفحه راهنمای کوتاه دارد |
| طراحی جذاب و مشتری‌پسند | ویترین با گرید کارت‌های عکس‌دار، بنر، انیمیشن، تم‌های رنگی و حالت شب |
| چند دسته‌بندی | بخش «دسته‌بندی‌ها» (با آیکن، رنگ، زیر‌دسته و کلمات کلیدی) |
| جزئیات کامل هر کالا + یک بارکد | صفحهٔ «جزئیات» هر کالا: مشخصات، گالری، توضیحات و **بارکد قابل خواندن با گوشی مشتری** + چاپ برچسب |
| اطلاع‌رسانی با شماره/ایمیل و زمان دلخواه | بخش «اطلاع‌رسانی خودکار»: بازهٔ روزانه/هفتگی/دوهفته‌ای/ماهانه + ساعت + گزارش کامل وضعیت فروشگاه |
| ثبت پایان روز با عکس یا نام + تعداد | بخش «پیام پایان روز»: بنویسید «۳ تا نوشابه فروختم و ۵ عدد آب معدنی اضافه شد» — خودش موجودی را اصلاح می‌کند |

## ۲) راه‌اندازی روی GitHub (۵ دقیقه)

1. وارد **github.com** شوید و یک مخزن (Repository) جدید بسازید — مثلاً با نام `myshop` (نوع Public).
2. در صفحهٔ مخزن، روی **Add file → Upload files** بزنید و **همهٔ فایل‌های این پوشه** را داخل آن بریزید
   (فایل‌های `index.html`، `admin.html`، `sw.js`، `manifest.webmanifest`، پوشهٔ `assets` و پوشهٔ `.github`).
   سپس **Commit changes**.
3. به **Settings → Pages** بروید.
4. در قسمت *Build and deployment*، حالت **Deploy from a branch** را انتخاب کنید، شاخهٔ `main` و پوشهٔ `/ (root)` را بگذارید و **Save** بزنید.
   *(اگر خواستید، می‌توانید حالت *GitHub Actions* را انتخاب کنید؛ فایل آماده‌اش در `.github/workflows/pages.yml` هست.)*
5. چند دقیقه صبر کنید (تب Actions را ببینید). آدرس سایت شما این می‌شود:

```
پنل مدیر          →   https://USERNAME.github.io/myshop/admin.html
فروشگاه مشتریان   →   https://USERNAME.github.io/myshop/
```

6. اول وارد پنل شوید، رمز را عوض کنید، اطلاعات فروشگاه و شمارهٔ واتساپ خود را در «تنظیمات» بگذارید، بعد اجناس را وارد کنید.

> 🧪 **تست سریع بدون آپلود:** اگر می‌خواهید همین حالا ببینید، فایل‌های `single-admin.html` و `single-store.html` نسخهٔ تک‌فایلی سایت هستند؛ روی فایل دوبار کلیک کنید و همان لحظه کار می‌کند (برای تست).

## ۳) کارهای روزمره در ۳۰ ثانیه

- **افزودن جنس:** پنل → «اجناس فروشگاه» → «افزودن جنس» → عکس را بکشید داخل کادر → «تحلیل هوشمند تصویر» → فرم خودش پر می‌شود → قیمت‌ها را بنویسید → «ثبت جنس». (در همان فرم، پیش‌نمایش برچسب و بارکد را می‌بینید.)
- **فروش سریع:** پنل → «فروش سریع» → روی کالاها بزنید (یا بارکد را اسکن کنید) → «ثبت فروش»؛ اگر بخواهید، فاکتور هم چاپ می‌شود.
- **کم/زیاد کردن قیمت:** پنل → «ماشین‌حساب قیمت» → قیمت خرید و فروش را بنویسید و دکمه‌های ‎+۵٪‎ / ‎−۱۰٪‎ / درصد دلخواه را بزنید، یا «تغییر گروهی قیمت» را روی همهٔ اجناس/یک دسته اجرا کنید.
- **پایان روز:** پنل → «پیام پایان روز» → جملهٔ خودتان را بنویسید → «تحلیل پیام» → بازبینی در جدول → «اعمال روی انبار و فروش».
- **اطلاع‌رسانی:** پنل → «اطلاع‌رسانی خودکار» → روش (ایمیل/واتساپ/تلگرام/وبهوک/اعلان مرورگر)، مقصد، بازه و ساعت را وارد کنید → «ذخیره» → «ارسال آزمایشی همین حالا».
- **مشتری:** آدرس `index.html` را به مشتری بدهید؛ خودش جست‌وجو می‌کند، جزئیات و بارکد را می‌بیند، سبد می‌بندد و سفارش را برای واتساپ شما می‌فرستد. سفارش‌ها در پنل، بخش «پیام پایان روز»، با یک کلیک به فروش و کسر از انبار تبدیل می‌شوند.

## ۴) نکته‌های مهم

- **کجا ذخیره می‌شود؟** در «حافظهٔ مرورگر» همان دستگاهی که کار می‌کنید (localStorage). هیچ اطلاعاتی جایی فرستاده نمی‌شود.
- **پشتیبان‌گیری:** پنل → «پشتیبان‌گیری» → «دانلود پشتیبان کامل (JSON)». هر چند وقت یک‌بار این کار را بکنید و فایل را جای امن نگه دارید. بازیابی همان‌جا انجام می‌شود.
- **اطلاع‌رسانی خودکار** بدون سرور کار می‌کند: چون سایت در مرورگر شما اجرا می‌شود، اگر صفحهٔ پنل باز باشد در ساعت مقرر گزارش ارسال می‌شود. برای ایمیل کاملاً خودکار (بدون باز شدن پنجره) یک حساب رایگان در **emailjs.com** بسازید و شناسه‌ها را در همان بخش وارد کنید. برای اطمینان می‌توانید هر زمان دکمهٔ «ارسال آزمایشی» را بزنید.
- **بدون اینترنت:** پس از اولین بازکردن، سایت آفلاین هم کار می‌کند (Service Worker). روی موبایل از منوی مرورگر «افزودن به صفحهٔ اصلی» را بزنید تا مثل یک اپ نصب شود.
- **چند دستگاه؟** چون سرور وجود ندارد، هر مرورگر حافظهٔ خودش را دارد. برای دیدن اطلاعات در دستگاه دیگر، فایل پشتیبان را بگیرید و همان‌جا بازیابی کنید.

## ۵) ساختار پوشه‌ها

```
shop/
├── index.html                ← فروشگاه مشتریان
├── admin.html                ← پنل مدیر (رمزدار)
├── sw.js                     ← کار آفلاین (Service Worker)
├── manifest.webmanifest      ← نصب روی گوشی
├── single-admin.html         ← نسخهٔ تک‌فایلی برای تست سریع
├── single-store.html         ← نسخهٔ تک‌فایلی برای تست سریع
├── tools/build-single.py     ← ساخت نسخه‌های تک‌فایلی
├── .github/workflows/pages.yml ← انتشار خودکار روی GitHub Pages
└── assets/
    ├── css/app.css           ← تمام استایل‌ها (راست‌به‌چپ، موبایل، حالت شب)
    ├── img/                  ← آیکن‌ها
    └── js/
        ├── util.js           ← ابزارها: تاریخ شمسی، اعداد فارسی، پیام‌ها، فرم‌ساز
        ├── barcode.js        ← ساخت و خواندن بارکد (EAN-13 / Code128)
        ├── vision.js         ← تحلیل هوشمند تصویر (Offline)
        ├── store.js          ← داده‌ها: اجناس، انبار، فروش، آمار، پشتیبان
        ├── nlp.js            ← فهم پیام فارسی پایان روز
        ├── notify.js         ← ساخت گزارش و ارسال (ایمیل/واتساپ/تلگرام/وبهوک)
        ├── ui.js             ← اجزای رابط: جدول، نمودار، چاپ، ماشین‌حساب
        ├── dash.js           ← صفحات پنل مدیر
        └── app.js            ← صفحات فروشگاه مشتریان
```

## ۶) پرسش‌های پرتکرار

**رمز را فراموش کردم.** در صفحهٔ ورود، «رمز را فراموش کرده‌ام» را بزنید؛ رمز به `admin123` برمی‌گردد و اطلاعات اجناس و فروش شما دست‌نخورده می‌ماند.

**موجودی را اشتباه زدم.** بخش «انبار و موجودی» → «افزودن/کاهش» یا «انبارگردانی» برای شمارش واقعی قفسه‌ها؛ همهٔ تغییرها در «گردش انبار» ثبت می‌شود.

**می‌خواهم قیمت‌ها را یک‌جا زیاد کنم.** «ماشین‌حساب قیمت» → «تغییر گروهی قیمت» → حالت درصدی، مثلاً `10` بگذارید و «اعمال» بزنید.

**عکس کالا تحلیل نشد.** عکس ساده با پس‌زمینهٔ یکدست (روی میز سفید) بهترین نتیجه را می‌دهد؛ اگر تشخیص مطمئن نبود، چهار گزینهٔ پیشنهادی با درصد نشان داده می‌شود و می‌توانید هر فیلد را خودتان ویرایش کنید.

**برای چاپ برچسب نیاز به چاپگر برچسب دارم؟** لازم نیست؛ برچسب‌ها روی کاغذ A4 چاپ می‌شوند (چاپگر معمولی) و بارکدشان با گوشی هم خوانده می‌شود.

## ۷) اجرای پروژه به‌صورت محلی (اختیاری)

اگر خواستید سایت را قبل از آپلود روی کامپیوتر خودتان ببینید، کافی است یک سرور ساده در همین پوشه اجرا کنید (مثلاً با پایتون):

```bash
python3 -m http.server 8000
# سپس در مرورگر:  http://localhost:8000/index.html
```

یا بدون هیچ ابزاری، فقط فایل‌های `single-store.html` و `single-admin.html` را باز کنید.
